# docs —— 这里放什么

本目录**只放历史存档**。当前有效的文档不在这里，避免同一份文件存在两个副本、改一边另一边不跟着变。

| 你要看的东西 | 去哪看 |
|--------------|--------|
| 当前架构说明（一看就懂版） | `技能源文件\image-data-recognition\references\架构说明.md` |
| 当前安装部署说明（含自检与自修复） | `技能源文件\image-data-recognition\references\安装部署说明.md` |
| 工作区行为手册（AI 必读、红线、流程） | `AGENTS.md`（工作区根目录） |
| 给员工看的大白话说明 | `使用说明.md`（工作区根目录） |
| 技能正文（AI 实际读的那份） | `技能源文件\image-data-recognition\SKILL.md` |

> 技能源文件是**唯一真源**：改动后重跑 `tools\安装技能（双击）.bat`，会自动同步到本机 7 个 AI 工具的技能目录。
> 上面两份说明文档只存在于技能里，工作区不再放副本。
