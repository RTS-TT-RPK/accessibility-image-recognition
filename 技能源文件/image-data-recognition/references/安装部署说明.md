# 安装部署说明 —— 图像数据识别转化

> 目标：换电脑、换工具，都不用懂技术。**技能就是一个文件夹，复制到对应位置即可。**
> 本版对应**技能 V2.0**（命令驱动流程：AI 只交识别片段，编号/换算/落盘/导入/长表/摘要都由脚本做）。

---

## 一、一句话说清这套东西的结构

| 部分 | 是什么 | 在哪 |
|------|--------|------|
| **技能源文件** | 告诉 AI"这件事怎么做"的说明书（唯一真源） | `图像识别长期工程\技能源文件\image-data-recognition\` |
| **工作区** | 你的数据、脚本、规则、归档 | `图像识别长期工程\`（本文件夹） |
| **已安装副本** | 各家 AI 工具实际读取的那一份 | 见下面第四节表格 |

**关键理解**：
- 技能 = 说明书，每个工具要装一份（工具只认自己家的目录）；
- 工作区 = 数据工厂，只有一个；
- **技能源文件跟着工作区走**，改完重新跑一次安装脚本，所有工具同步更新。

## 三、装上/更新技能（一步）

**双击 `tools\安装技能（双击）.bat`** 即可。

它会自动：
1. 检测本机装了哪些 AI 工具（看配置目录在不在）；
2. 把技能复制到每个工具的技能目录；
3. 往每份副本写一个 `workspace.txt`，写明工作区在哪（这样 AI 自己就能找到工作区）；
4. 顺便在工作区里也放一份（`项目级`），有些工具打开文件夹时会直接读到。

只想看看检测结果、先不安装：命令提示符里运行 `python tools\安装技能.py --list`

**什么时候要重跑这个脚本？**
- 技能源文件改了（比如 AI 帮你更新了文档）；
- 换了一台电脑；
- 新装了一个 AI 工具；
- 工作区挪了位置（换了盘符或文件夹名）。

### DSH 专用插件（可选，只有 DSH 用得上）

技能是"说明书"，装到哪家工具都能用。而 **DSH 还多一个专用插件** `dsh-table-image`：
它把建任务/提交识别/审核这套动作做成 DSH 里的工具按钮。

- **日常做法**：双击 **`tools\安装DSH插件（双击）.bat`**（它就是下面这个安装器的双击外壳）；
- **DSH 专用插件安装器**：
  `tools\dsh_plugin_setup.py` —— 装 / 查 / 卸都由它负责：

  ```powershell
  python tools\dsh_plugin_setup.py --status      # 看装没装、挂没挂上（不改任何东西）
  python tools\dsh_plugin_setup.py               # 装（或更新）
  python tools\dsh_plugin_setup.py --dry-run     # 只显示会改什么，不动任何文件
  python tools\dsh_plugin_setup.py --uninstall   # 卸掉（配置改回去，备份留着）
  python tools\dsh_plugin_setup.py --no-verify   # 跳过 pnpm --dump-config 校验
  ```

  它只动四处：profile 的 `node_modules` 链接、profile 的 `package.json`、
  profile 的 `cordis.patch.yml`（只追加/修改**顶格**覆盖项）、技能目录 `~/.dsh/skills`；
  改前一律先备份，写完自检不过就放弃写入（绝不覆盖原配置）。
  **装完必须重启 DSH**，界面再按 **F5** 刷新。
- 是不是每个工具都要装它？**不用。** 不装插件，AI 照样能用技能跑完整流程
  （就是纯命令行）；插件只是让 DSH 里多几个按钮。
- 插件源在工作区 `插件源文件\dsh-table-image\`（本说明不覆盖它的内部结构）。

## 六、换电脑搬家（三步）

### 第 1 步：在旧电脑上打包

双击工作区里的 **`tools\打包技能包.bat`**
→ 在 `发布` 文件夹里生成一个压缩包（约 0.3 MB，比一张照片还小）。

> 想把"标准答案库 golden"也一起带走（推荐长期做）：
> 命令提示符运行 `python tools\导出技能包.py --with-golden`

### 第 2 步：把压缩包拷到新电脑

U 盘 / 微信 / 钉钉 / 网盘 / 公司共享盘，任选。
**不需要 GitHub、不需要注册账号、不需要联网。**

### 第 3 步：在新电脑上安装

1. 解压压缩包，得到"表格识别系统"文件夹；
2. 双击 **`tools\安装环境（双击）.bat`** —— 检查 Python、离线安装依赖库；
3. 双击 **`tools\安装技能（双击）.bat`** —— 把技能装进新电脑上所有 AI 工具；
4. **跑一遍脚本层自测**：`python tools\新流程自测.py`（结尾应是 `失败 0 项`）；
5. 用 AI 工具打开这个文件夹即可开始。

> "把这个技能装到本机所有 AI 工具里"，它会读 `技能源文件` 并完成复制。

## 八、技能自检与自修复（AI 做的事）

技能被加载后，AI 第一件事是**确认工作区在哪**，顺序是：

1. 读技能目录下的 `workspace.txt`；
2. 路径有效 → 直接用；
3. 无效或缺失 → 在当前打开的项目里找 `validate_export.py`；
4. 还找不到 → 在桌面找名字含「图像识别长期工程」的文件夹；
5. 全找不到 → **直接问用户**，拿到答复后写回 `workspace.txt`。

这条链保证了：工作区挪了位置、换了电脑、换了盘符，技能都不会"装死"。

自检命令（都在工作区根目录下运行）：

```powershell
python tools\环境自检.py        # Python / 依赖 / 技能安装 / workspace.txt 编码
python tools\新流程自测.py      # 脚本层端到端自测（临时目录里跑，真实数据只读）
python tools\回归测试.py        # 裁判脚本的行为没被改坏

# DSH 专项自检：会打印 DSH 到底扫描哪些目录、有没有发现本技能
node tools\DSH技能自检.mjs "C:\Users\86173\Desktop\图像识别长期工程"

# DSH 插件装没装、挂没挂上
python tools\dsh_plugin_setup.py --status
```

## 十、日常使用（装好之后）

1. 照片丢进 `inbox\`；
2. 对 AI 说：**"处理今天的图"**；
3. 审核它生成的 `task_review.xlsx`，**填两列**：
   - 「问题清单」页的**员工决定**；
   - 「文件归档清单」页的**是否归档**（想改名字就改「建议文件名」那一列）；
4. 说一句"**审核完成**"——AI 会先用 `tools\导入审核.py` 把你的填写存成正式记录，再重跑；
5. 拿到 `final.xlsx`（给人看）和 `facts.jsonl`（给机器读），照片已自动归档；
6. 它会念一句交付摘要（几张图、几行、几个问题、归档到哪）——那些数字是脚本从文件里读的。

## 十一、常见问题

**Q：bat 双击一闪而过？**
右键"以管理员身份运行"，或先开"命令提示符"再运行，报错就能看见了。

**Q：提示找不到 Python？**
去 python.org 下载 3.10 以上版本；安装界面最下面**务必勾选 "Add python.exe to PATH"**，装完再双击安装脚本。

**Q：能不用 GitHub 吗？**
能，而且**本来就该不用**。整个系统就是一个文件夹，复制即迁移。GitHub 是给程序员传代码用的，你们不需要。

**Q：某个工具里没看到这个技能？**
1. 先确认那个工具的配置目录存在（比如 `%USERPROFILE%\.cursor\`）；
2. 重新跑一次 `tools\安装技能.py`；
3. 重启那个工具；
4. 还不行就告诉 AI："技能没被识别到，帮我查一下这个工具读哪个目录。"

**Q：怎么升级系统？**
拿到新版压缩包，解压后**只覆盖这些**：
`技能源文件\`、`validate_export.py`、`AGENTS.md`、`README.md`、`使用说明.md`、`AI自安装说明.md`、
`schemas\README.md`、`runs\README.md`、`tools\`（含 V2.0 新增的
`建任务.py`、`提交识别.py`、`导入审核.py`、`注册表型.py`、`导出长表.py`、`收尾报告.py`、
`收录.py`、`新流程自测.py`、`dsh_plugin_setup.py`）。
**不要覆盖** `runs\`、`golden\`、`archive\`、`aliases.json`、`FEEDBACK_LOG.md`（这些是你的数据）。
覆盖完重跑一次 `tools\安装技能（双击）.bat`，再跑一遍 `python tools\新流程自测.py` 确认脚本层是好的。

> 注意：升级**不要动** `schemas\` 里已有的契约（尤其别覆盖成示例文件）——
> 那些是你确认过的规则；新表型一律由 `tools\注册表型.py` 新增 `_vN`。

**Q：`新流程自测.py` 报"失败 N 项"怎么办？**
说明 `tools\` 下的脚本这份拷贝跑不通（版本不齐、被改动、权限或编码问题）。
把失败项原文发给开发者，**先不要拿真实照片去跑**——免得在没验证过的脚本上处理真数据。
它是只读真实数据的，随便跑不会弄坏任何东西。

**Q：`--status` 说"① 未开始"，可任务明明做了一半？**
八成是 `raw.json` 被带 BOM 的编辑器（记事本"另存为 UTF-8"）存过了。
裁判脚本按不带 BOM 的 UTF-8 读它，读不出来就当成"空"。**别手改 `raw.json`**——
它只由 `tools\提交识别.py` 写；要改数据请走审核表 + `tools\导入审核.py`。

**Q：数据怎么做备份？**
复制 `archive\` + `runs\` + `golden\` 三个文件夹到移动硬盘或网盘即可。恢复时放回原位。

**Q：能不能放在共享盘多人用？**
可以放共享盘，但**同一时间只让一个人处理**（避免两个任务同时改同一个文件）。多人协作更适合各自电脑跑，最后汇总 `golden\`。

**Q：公司电脑不让装软件、也不让跑脚本怎么办？**
脚本一个字都不改，但**跑不了脚本就只能手工做**（不推荐）。最低限度也要让 Python 能跑，
因为 V2.0 的编号、换算、导入审核都靠脚本——手工做等于把这套系统的核心防线拆了。
真跑不了时，把 `技能源文件\image-data-recognition\` 文件夹手动复制到对应工具的技能目录（见第七节），
再用记事本建一个 `workspace.txt` 写一行路径，并**明确告知使用者：数据准确性由人工负责**。
