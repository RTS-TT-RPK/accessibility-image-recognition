# 命令速查 —— 每一步照抄就行

> 所有命令都在**工作区目录里**运行（先 `cd` 到工作区，或用工具的"工作目录"设置）。
> 工作区路径写在本技能目录的 `workspace.txt` 里。

---

## 零、首选用法：一个入口，8 个动词

```bash
python tools\任务.py new                    # 收 inbox 建任务
python tools\任务.py next                   # 下一张待识别的图 + 该填的格式
python tools\任务.py submit < 片段.json      # 交一张（片段走标准输入）
python tools\任务.py status                 # 进度 + 下一步
python tools\任务.py check                  # 全部识别完后刷新问题账本
python tools\任务.py review                 # 生成审核表交给用户
python tools\任务.py import                 # Excel → decisions.json
python tools\任务.py finalize               # 落账 + 归档 + 长表 + 摘要
```

**不用给任务号**（自动挑"最新且还没干完"的那个，`--run 20260910_003` 可指定），
**不用给图片编号**（从片段里读 `image_id`），**不用给文件路径**（片段从标准输入进）。
调度器内部不含业务逻辑，它只是替你把下面那些完整命令拼好、原样转达脚本的输出。

> 下面各节是**完整命令**与更细的用法 —— 调度器不够用时直接跑它们。

---

## 一、AI 的活只有这三件

| AI 干 | 脚本干 |
|------|--------|
| ① 用 `read_image` 看图 | 建任务、复制原图、算指纹 |
| ② 写"这张图上我看到了什么"的片段 | 编号、单位换算、必填字段、合并落盘 |
| ③ 把用户的大白话转成决定 | 校验、记账、生成 Excel、改名归档、出摘要 |

**别自己写 `raw.json`，别自己换算，别自己起文件名。**

## 二、每次开工先看进度

```bash
python validate_export.py runs/20260910_001 --status     # 完整进度 + 下一步该干什么
python tools/提交识别.py runs/20260910_001 --list         # 只看识别阶段进度
```

## 三、阶段一：立样板

```bash
# 1. 收图建任务（从 inbox 收全部；也可以把图片路径写在后面只收指定的几张）
python tools/建任务.py
python tools/建任务.py --dry-run                  # 先看看会收哪些，不写任何东西
python tools/建任务.py 照片1.jpg 照片2.jpg          # 只收指定的
python tools/建任务.py --skip-duplicates          # 和前任务重复的图直接跳过

# 2. 看下一张待识别的图（会打印：绝对路径 / 图片编号 / 已注册表型 / 片段格式）
python tools/提交识别.py runs/20260910_001 --next

# 3. 看图 → 写片段 → 提交
python tools/提交识别.py runs/20260910_001 --image IMG_001 --file 片段.json
python tools/提交识别.py runs/20260910_001 --image IMG_001 --stdin          # 从管道读
python tools/提交识别.py runs/20260910_001 --image IMG_001 --file 片段.json --replace   # 重交覆盖

# 4. 出样板给人看
python tools/生成样板.py runs/20260910_001                        # 全部图
python tools/生成样板.py runs/20260910_001 IMG_001                # 只针对某一张

# 5. 用户确认后，落成正式契约（硬拦：row_unit 没被回答写不进去）
python tools/注册表型.py runs/20260910_001 --name 来料分析 \
  --row-unit "一行 = 一个样品（一个桶 / 一批）" \
  --name-pattern "{date}_{sheet}_{batch}_第{n}张" \
  --notes "用户说桶号那列其实叫罐号，已改"
```

## 八、退出码约定

| 退出码 | 含义 |
|--------|------|
| 0 | 成功（`validate_export.py` 的情况：**0 不代表没有问题**，问题在 `issues.json` 里） |
| 1 | 有断言失败（`回归测试.py` / `新流程自测.py`）；或未预料的异常 |
| 2 | 被拒绝 / 参数错误（片段不合格、契约缺确认、找不到任务目录等）——**这次什么都没写** |

`validate_export.py` 的 0 只表示"跑完了"，**必须看它打印的问题条数或读 `issues.json`**。

## 九、文件都是谁写的

| 文件 | 谁写 | 能不能改 |
|------|------|----------|
| `runs/<任务>/source/names.json` | `建任务.py` | 不要手改 |
| `runs/<任务>/raw.json` | `提交识别.py`（**唯一写手**） | 不要手改 |
| `runs/<任务>/sample.json` | `注册表型.py` | 不要手改 |
| `runs/<任务>/decisions.json` | `导入审核.py` | 可以手改（权威记录） |
| `runs/<任务>/issues.json`、`final.xlsx`、`task_review.xlsx`、`archive_plan.json` | `validate_export.py` | 派生文件，重跑会重写 |
| `runs/<任务>/facts.jsonl` | `导出长表.py` | 派生文件 |
| `schemas/*.json` | `注册表型.py`（或人手写） | 改版 = 新增 `_v2`，旧版永久保留 |
| `aliases.json`、`FEEDBACK_LOG.md`、`golden/` | `收录.py`（用户拍板后） | **只追加** |
| `validate_export.py` | 人（必须拍板 + 回归全绿） | **AI 不许改** |
