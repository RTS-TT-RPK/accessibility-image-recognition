# 表格图片转录工作流（图像数据识别转化）

把**任意表格图片**——手机拍的纸质单据、电脑截图、扫描件，印刷体或手写体，任意行业——
变成**可信的结构化数据**。

**三步走：做样板 → 批量转录 → 一次性复核。**

> **AI 只做三件事：① 看图 ② 判断新表型的列名 ③ 把用户的话转成决定。**
> 编号、换算、必填、落盘、校验、改名、归档、记账 —— **全部有脚本，照抄命令就行，
> 不要自己算、不要自己写、不要自己拼 raw.json。**

---

## 最快的用法：一个入口，8 个动词（先看这里）

**在工作区目录里跑 `tools\任务.py`，动词固定、不用带任务号和图片编号。**

| 动词 | 干什么 |
|------|--------|
| `python tools\任务.py new` | 收 `inbox` 里的图，建任务 |
| `python tools\任务.py next` | 看下一张待识别的图 + 该填的片段格式 |
| `python tools\任务.py submit < 片段.json` | 交一张图的识别结果（片段走标准输入） |
| `python tools\任务.py status` | 看进度 + 下一步该干什么 |
| `python tools\任务.py check` | 全部识别完后刷新问题账本 |
| `python tools\任务.py review` | 生成审核表（`task_review.xlsx`）交给用户 |
| `python tools\任务.py import` | 用户填完后，把 Excel 导成 `decisions.json` |
| `python tools\任务.py finalize` | 落账 + 归档 + 出长表 + 出交付摘要 |

**为什么这样更不容易错**：任务号是调度器自己扫出来挑的（挑"最新且还没干完"的那个），
图片编号是从片段 JSON 里自己读的（片段顶层就有 `image_id`），片段从标准输入进（绕开中文文件路径）。
**你只需要记住 8 个词，不需要拼任何路径。**

想指定别的任务：任何动词后面都可以加 `--run 20260910_003`。

> 下面各阶段给的是**完整命令**（调度器内部调的就是这些）。两边等价，
> 想看清楚每一步到底做了什么、或者某个动词不够用时，直接跑完整命令也可以。

---

## 模型怎么选（本技能不绑定任何模型）

**任何有多模态能力的模型都能用**，不挑牌子、不需要本地部署。因为模型与流程之间
只有一个接口：**识别片段**（看图 → 交一小段"这张图上我看到了什么"）。

换模型不破坏任何东西：历史数据不变、已填的人工决定不变（按 `issue_id` 存，与模型无关）、
不需要改任何脚本或契约。

**怎么判断一个模型够不够用：用样板试，不要用一百张图试。**
做样板时就盯着看：**该进 `uncertain` 的地方，它是不是硬填了个值？**
到处是"看着像就填"的痕迹 → 换模型；看不清的都老实标了 → 这个模型能用。

两条实操建议：**同一批图用同一个模型**；**换了模型最好重做一次样板**（成本一张图）。

---

## 第 0 步：先找到工作区（每次都要做）

1. 读本技能目录下的 `workspace.txt`（一行工作区绝对路径）。
2. 路径有效 → 用它；**以下所有命令都在工作区里、以工作区为当前目录运行**。
3. 缺失或路径失效 → 找当前项目里的 `validate_export.py`；再找桌面含「图像识别长期工程」的文件夹；
   都找不到 → **直接问用户**，拿到答复后写回 `workspace.txt`
   （**必须 UTF-8 带 BOM**，Python 用 `encoding="utf-8-sig"` 读写）。
4. 骨架不全就跑 `python tools/初始化工作区.py`；环境不确定就跑 `python tools/环境自检.py`。

---

## 铁律（任何时候都不许破）

1. **不猜**：看不清就写进 `uncertain`；日期认不出就留空，**绝不默认成今天**。
2. **不造数**：图上空白就留白；脚本也不补算，**绝不填一个"看起来合理"的值**。
3. **不覆盖**：归档只交给裁判脚本；不删 `inbox/`、`pending/` 里未处理的图；不改 `golden/` 历史条目。
4. **不改裁判**：`validate_export.py` 是唯一裁判，改动必须由人拍板，改完必须回归测试全绿。
5. **不静默**：任何"我改了 / 我跳过了 / 我没看懂"都必须写进汇报。
6. **不手写数据**：`raw.json` 只由脚本写；你只交识别片段，格式见下。

# 阶段一：立样板（1 张图，人确认一次）

**为什么要有这一步**：直接问用户"这张表有哪些列、一行代表什么"太抽象；
**做出来给他看，他一眼就知道对不对。**

```bash
# ① 收图建任务：建 runs/日期_编号/、复制原图、算指纹、写图片台账和空骨架
python tools/建任务.py

# ② 看下一张待识别的图（打印绝对路径、已注册表型、要填的片段格式）
python tools/提交识别.py runs/20260910_001 --next
```

> **挑样板图要挑有代表性的，不要挑最清楚的**（要能代表这批图的真实难度）。
> 这批图明显有两种以上版式，就做两个样板，别硬凑成一个。

③ **用 read_image 看那张图**，把这一张的识别结果写成片段 JSON，提交：

```bash
python tools/提交识别.py runs/20260910_001 --image IMG_001 --file 片段.json   # 或用 --stdin
```

片段格式（**只写图上看到的东西**）：

```json
{
  "image_id": "IMG_001",
  "sheet_label": "来料分析",
  "date_text": "2026-09-10",
  "rows": [
    {"row_role": "data",
     "object_label": "A001/桶01",
     "fields": {"日期": "2026-09-10", "物料": "IPAC", "批次": "A001", "桶号": "01"},
     "components": [{"name": "IPAC", "raw_value": "89.6%"}],
     "uncertain": [{"field": "乙酸", "candidates": ["0.5%", "5%"], "note": "字迹不清"}]}
  ]
}
```

> **不要写** `row_id`、`value`、`unit`、`required_fields`、`suggested_name`、`sha256`、`file` —— 脚本自己算。
> `components` 的 `raw_value` 写**图上原文**（`89.6%`），换算由脚本做。
> 表头行、合计行、备注行也要写，`row_role` 标成 `header` / `summary` / `note`；
> **`row_role` 缺失的行会被当场退回**（身份不明的行不能当数据用）。
> 图片是哪种表，从 `--next` 打印的**已注册表型**里挑；**不要自己发明新列**。

④ 生成样板给人看：

```bash
python tools/生成样板.py runs/20260910_001
```

把 `样板.xlsx` 交给用户，请他在**第 5 页签**写确认意见。要问的就那几件事：
这个录法对不对、一行代表什么、列名行不行、哪些必填、有没有合计、哪些词是一回事、
看不清的格子到底是什么。

⑤ 用户确认后，把草案落成正式契约
（**硬拦：`row_unit` 没被用户回答就写不进去**）：

```bash
python tools/注册表型.py runs/20260910_001 --name 来料分析 \
  --row-unit "一行 = 一个样品（一个桶 / 一批）" \
  --name-pattern "{date}_{sheet}_{batch}_第{n}张" \
  --notes "用户说桶号那列其实叫罐号，已改"
```

它会写 `schemas/<表型名>_v1.json` + `runs/<任务>/sample.json`，并**自动跑一遍回归测试**。
用户提了修改 → 改草案重出一版样板再确认，**可以来回几次，数据不会丢**。

> **已有契约的表型可以跳过阶段一**，直接从阶段二开始。

---

# 阶段二：批量转录（闷头干完，不许中途打扰用户）

**原则：一口气做完，疑点全部记账，不停下来问人。**

```bash
python tools/提交识别.py runs/20260910_001 --next                 # 看下一张
#   → read_image 看图 → 写片段 → 提交
python tools/提交识别.py runs/20260910_001 --image IMG_002 --file 片段.json
```

- **脚本每收一张就立刻落盘**（原子写），断电、关机、人走开都不丢进度。
- 提交被**拒绝**（退出码 2）→ 按它列出的理由改片段再交一次。**被拒绝时什么都没写。**
- 提交成功但**裁判报了疑点**（合计超百、同类词未注册…）→ 那是正常流程，
  **已经记账了，继续做下一张**，不要停下来问用户。
- 版式和样板不一样 → **照实记、标好 `row_role`，不要自己发明新列**。
  确实需要新列 → 走阶段一给这个版式注册一份新契约。

全部识别完，刷新账本：

```bash
python validate_export.py runs/20260910_001 --init-issues
```

---

# 阶段三：一次性复核（人只看一次）

```bash
python validate_export.py runs/20260910_001        # ① 生成审核表
```

把 `task_review.xlsx` 交给用户，请他**只填「问题清单」页的「员工决定」列**，
以及「文件归档清单」页的「是否归档」列。没有问题的数据不用逐行确认，
看「审核总览」就知道今天录了几张、几个问题。

```bash
# ② 用户说"审核完成"后，把 Excel 里的填写导入成权威记录（不要再手抄！）
python tools/导入审核.py runs/20260910_001

# ③ 重跑 + 归档 + 出长表 + 出交付摘要
python validate_export.py runs/20260910_001 --archive
python tools/导出长表.py runs/20260910_001
python tools/收尾报告.py runs/20260910_001
```

`decisions.json` 才是权威（Excel 是派生的、重跑会整表重写）——`导入审核.py` 就是干这个的，
**这一步不能再用人工誊抄**。需要更新词典 / 错题本 / 标准答案库时：

```bash
python tools/收录.py aliases  runs/20260910_001    # 只收录用户明确拍板过的同类词
python tools/收录.py golden   runs/20260910_001    # 只追加已确认的事实
python tools/收录.py feedback runs/20260910_001 --field 乙酸 --wrong "0.8%" --right "0.0%" --type 视觉误读
```

④ **汇报**：把 `收尾报告.py` 的"一句话"念给用户（表型、行数、问题数、归档结果、文件路径）。
**数字用脚本打印的，不要凭记忆说。**

## 人工决定的写法（用户写在 Excel 里，脚本会校验）

- `字段名=值` → 修正对应字段 / 计量项；
- `通过` / `确认无误` / `照录` → 按原样接受，不再阻塞；
- `沿用候选A` / `沿用候选B` → 采用问题清单给的候选值；
- `见备注` → 只看备注、不改数据（该行保持阻塞，直到给出真实值）。

数值不合格（解析不出来）→ `导入审核.py` 会**拒绝并说明理由**，
请用户确认，**不要替他换算**。

---

## 中断与断点续跑

**任何时候问"做到哪了"，先跑命令，然后转述它的输出，不要凭记忆回答：**

```bash
python validate_export.py runs/20260910_001 --status     # 完整进度（含校验/审核/归档）
python tools/提交识别.py runs/20260910_001 --list         # 识别阶段进度
```

中断后的固定动作：跑 `--status` → **只补没做完的部分** → 继续往下走。
重复跑同一条命令是安全的：已完成的会跳过，人工决定会保留。

---

## 出错怎么办

| 情况 | 处理 |
|------|------|
| 图看不清/倾斜/太暗 | 请用户重拍；原图放 `pending/` |
| `提交识别.py` 拒绝 | 按理由改片段；缺 `row_role`／列名不在契约里／数值解析不了都会被拒 |
| 样板被用户否了 | 按意见改契约（或换一张更有代表性的样板图），重新确认 |
| 校验报"合计超上限" | 进问题清单，请用户对照原图给正确值，**不要自行修改** |
| 报"表名不在已注册契约里" | 这批图里混了别的表型，或表名跟样板写得不一样——**不要忽略** |
| 报"结构异常" | `raw.json` 畸形，脚本会尽量救回并如实报出，**在汇报里说明** |
| 归档目标同名 | 脚本自动加 `_2`；绝不覆盖 |
| 审核表填了没导入就重跑 | `收尾报告.py` 会告警；**先跑 `导入审核.py`**，否则新填的会被冲掉 |
| 脚本报"schema 读不了，已跳过" | 契约写坏了，**立刻修**，别当成提示忽略 |
| 任务跑一半中断 | 重跑同一条命令；已落盘内容会复用，人工决定不会丢 |
